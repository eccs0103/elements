# Elements
Duel an AI that learned by playing itself. 60 seconds, a 41×41 board, 38 elements that grow, burn and destroy each other.

![Gameplay](./resources/gameplay.png)

**[Play at elements.eccs.dev](https://elements.eccs.dev/)**

## How a match works
- Pick the 10 elements you bring on the Deck page.
- Drag a card onto your side of the board. The next card is ready 3 seconds later.
- Elements react to each other, your own cells too.
- After 60 seconds, whoever owns more cells wins. A tie is yours.

## Arena or Practice
- **Arena:** every visitor plays the same AI, and each win counts for Humanity. Can Humanity out-score it?
- **Practice:** the same match, free and not counted.
